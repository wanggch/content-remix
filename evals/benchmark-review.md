# 对标语义复核回归案例

用途：给后续代理创作评估使用的正反例，不是已经执行的模型效果测试。检查应引用证据、指出问题并修订，不得只数关键词或复述检查表。

| 输入差异 | 预期判断 |
|---|---|
| 原文不拿伴侣比较；新稿改成犯错不数落，却称六维全保留 | 识别核心维度替换，补回或说明实质取舍，不视为同义例子 |
| 原文支持事业和兴趣；新稿仅听摄影，却称覆盖相同 | 识别缩窄，修订内容或承诺 |
| 删除占3条就幸福，只留看看像不像你 | 检查正向收益是否流失，不要求恢复虚构阈值 |
| 记住洗发水品牌，标题说比他自己更清楚 | 证据不支持比较程度，应降低断言或换证据 |
| 找到车位就称周到；打翻花盆配最痛苦 | 分别识别例证弱连接与情绪尺度错位 |
| 普通夫妻亲近清单每条都要求出差、摄影、特定运动 | 识别累积代入门槛，不把具体等同高质量 |
| 摄影师伴侣主题使用摄影例子 | 不因出现摄影就判错，前提属于选题本身 |
| 表现清单多数句子是必须、应该、不要 | 结合实际阅读任务识别教学漂移，而非单看词 |
| 教程有明确步骤和必要提醒 | 不将正常教学误判说教，不机械删指令 |
| 文字概述几种靠近行为，画面只取散步挽手 | 允许取一个例子，不强迫一图画所有句子 |
| 为减少生成难度全部删掉原本承担情绪的台词 | 评估表达损失，按需要恢复，不要求每图气泡 |
| 原图本无气泡，新作保留无气泡且表达完整 | 允许保留，不机械要求增加台词 |
| 正文向丈夫说你，宝妈读者可认同并转发 | 受众与叙述对象分开，不强制改代词 |
| 缺少原图但声称逐图复核通过 | 标证据不足，不能虚构，按阻碍程度处理 |

执行记录要求：原文定位、新稿定位、问题/可接受差异、实际修订及复查。程序单元测试仅验证规范连接，不算上述语义案例已通过。
