# 选题贴近边界检查（合成输入，非用户认可作品）

共同输入：某参考文章的读者是妻子，任务是通过日常表达让丈夫的具体付出被看见，采用并列话术＋生活解释。此为检查用抽象摘要，不冒称真实原文。

| 候选/条件 | 预期判断 | 原因 |
|---|---|---|
| 同样帮助妻子表达认可，独立设计说法与日常例子，标题承诺具体的表达方法 | 选题可通过，原创与形式另查 | 同一读者、主体、问题和收益，未强制复用原句 |
| 改为丈夫如何接手儿保和带娃，画风保持相似 | 选题不通过 | 主体与任务改变，只剩同赛道关联 |
| 标题“幸福婚姻的终极智慧”，正文仍是表达认可 | 标题承诺不通过 | 标题过宽、夸大，未保持具体阅读收益 |
| 复制参考话术，仅替换称谓和个别名词 | 原创不通过 | 选题接近不能抵消表达抄用 |
| 用户明确要求换成丈夫分担育儿 | 可作为授权拓展，不称贴近原选题 | 本次指令优先，记录变化依据 |
| 只有链接但无法读取正文或图片 | 选题锚点待评 | 不猜测主体任务与原文结构 |
| 历史上写过相同任务，自动改成亲子教育 | 选题不通过 | 去重不能成为擅自跨任务理由，优先换具体表达 |

## 本轮规则对照

已逐项检查规则：SKILL.md选题章节及analysis-rubric.md覆盖上述边界；这是文档语义检查，不是独立模型执行或真实创作质量评测。下一次真实输入应保留选题锚点表和去标题判断供用户核验。
