# 贴图类公众号文章拆解规则

## 分析输出结构（保存为 对标资料/对标主题/对标分析.md）

只记录原文观察、机制与边界，可被多篇引用。本篇原创选题取舍另写文章创作资料/选题承接.md或选题与分镜.md，不混在共享原文拆解中。

1. **素材与可信度**：原文标题、来源链接或文件路径、正文和配图是否完整；不能看到的部分标为“未知”。
2. **人群与场景**：读者画像、核心现实处境、用户为什么会转发/收藏（标为推测）。
3. **标题点击机制**：不仅识别冲突、反差、悬念、共鸣，还说明读者的具体顾虑、承诺收益、行动门槛、可兑现的信息缺口与口语节奏。不要只替换关键词或为了短删掉有效收益；先按 `title-strategy.md` 用原标题公式演变10个主题标题，用户确认标题及大纲后才创作。
4. **核心表达**：一句话的主题；文章发生了什么/想说什么；具体生活细节。
5. **内容结构**：先识别并列话术卡/连续故事/前后对照/步骤教程；未知则说明。并列逐卡分析，故事看因果，对照看可比条件，教程看操作顺序。逐图记录角色、场景、主要事件、文字、情绪、设计元素和证据出处。
6. **语言风格**：句式长短、口语程度、对话/独白、留白、是否有空泛套话。
7. **视觉风格**：写实/插画/手绘等；画面比例、镜头、用色、光线、固定角色、是否嵌字、文字区；不清楚就标未知。
8. **传播机制**：认同、代入、争议、转发理由、互动提问（只能推测，不假称后台数据）。
9. **抽象可复用规律**：主题如何切、四图各司何职、阅读停留怎样设计；描述结构而不是复制表面表达。
10. **原创避让**：原文独特句式、具体场景、人物、视觉构图有哪些不得复刻；拟转化成哪些不同原创元素。

## 选题贴近：先固定具体读者需求

在选题章节列出“对标 / 本次 / 证据或用户改动依据”，逐项核对目标读者、人物关系、表达主体与视角、具体问题、核心情绪、阅读收益。以账号明确定位为先，区分实际读者、叙述对象、人称和分享对象；不从代词推断受众，也不强制保持或改写人称。保持账号受众与可解释的对标联系，演变10个不同问题，不把同题换词当新选题。没有可读证据则标待评，不依据赛道标签或标题臆测原文。

标题应承诺相近的具体收益，不扩大成泛泛的婚姻、成长或人生主题；可以保留常见标题机制，不照搬独特句式、也不只换关键词。原创同时体现在选题新切口与具体表达；新读者任务需由用户选定标题并确认大纲。

去标题检查：拿掉标题，新方案与原文、其余候选方案是否确实有不同的具体问题？若完全相同则只是换皮；若只剩同赛道则联系过弱。写出继承机制与变化依据，供用户选择。标题确认后交大纲文件，大纲确认后才能写分镜；选定后不得擅自切换主体和任务。

## 分镜前固定创作约束

标题和大纲均确认后，将内容结构、文字层级、文案篇幅、语言语感、通用视觉五项的原文观察、本次采用与证据填入 cards.json 的 format_contract，先生成 `创作资料/创作约束.md` 再写分镜。素材缺失用unknown，不虚构；用户要求改变形式时记录依据。人物一致性与场景连续性分别判断。

## 对标贴近度（分镜前及交付前均检查）

列出保留/改写/避让表，并检查：
1. 内容结构是否符合对标或用户要求？是否无故套用连续剧情？
2. 气泡、画面、解释等信息层级是否保留？
3. 单图文字量是否与样本相近，是否把解释错误删成标语？
4. 口语、举例、情绪推进是否相近，而非变成概念说明？
5. 泛化画风与版式是否接近，是否无故改成另一个视觉类型？

通用形式允许保留，原句、具体故事、独特角色与构图不照搬。两项以上明显偏离且未获用户要求时，先修订方案。不用“差异化”一项掩盖对标缺失。

## 形式贴近与内容原创：独立评价

在 `创作资料/选题与分镜.md` 为每个候选写“保留的具体问题、标题承诺与通用表达机制 / 独立创作的话术、例子和画面”。保持已确认标题与大纲的具体读者任务，独立设计表达，不通过替换人物称谓冒充原创，也不强制替换内容核心。选题贴近单独给结论，不能用形式相似或表达原创掩盖选题偏离。

选定方案及交付前分别记录下表，使用 PASS / WARN / FAIL / 待评，附原素材位置和本次卡片证据，不合并为总分：

| 评价轴 | 检查内容 | 不应混淆 |
|---|---|---|
| 形式贴近 | 结构、文字层级、阅读量、口语节奏、视觉密度是否符合对标或用户明确要求 | 原创不要求主动改掉有效的通用形式 |
| 内容原创 | 冲突、例子、话术、人物动作与解决办法是否独立设计；是否避让可识别表达 | 形式相似不能成为仅换词、复刻情节或构图的理由 |

形式偏离时修正组织方式；内容近似时重写具体表达。缺对标则对应比较写待评，不以模型自评证明原创。提示词阶段只能检查计划中的视觉形式，实际画风与密度需看成图。

## 视觉约束的具体化

用户要求贴近对标视觉时，不停留在“白底卡通、柔和配色”。实际查看样本后，分别描述人物简化程度（眼睛、发形、衣服细节）、景别与人物占比、气泡尺度与位置、留白、线条/色块质感、正文粗细和行距。数值若为创作建议而非测量，应明确标注。保留通用视觉形式并独立设计人物与场景，避免用“原创”作为主动换画风的理由。

仅用户另行要求图片审核时，才将实际成图与已查看样本逐项比较，记录每张差异及整组一致性；不设置先试首张或逐张确认关卡。风格偏差明显时说明阻断或偏差依据，等待用户决策，不自动重生成。白底正常、文字准确不代表形式贴近通过。没有参考图输入时说明只使用文字约束，不声称模型看过原图。

## 置信度

- 高：实际读到了完整原文及对应图片。
- 中：读到部分正文或部分图片。
- 低：仅有标题或二手描述，禁止臆测画风与逐图故事。

## 非法或不当模仿的处理

不要删除水印、抹除署名、复用原作者作品作为自己的原创图。可以提炼一般创作手法，但要独立生成文案和画面。原始素材仅用于参考和内部分析，保留来源记录；对外发表时自行核查授权和平台规范。
