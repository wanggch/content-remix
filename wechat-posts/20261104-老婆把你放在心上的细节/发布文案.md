# 发布标题

## 首选
老婆爱老公的6种表现，原来你也给了他这么多温柔

保留六条表现清单，在自我对照之外提供“自己的心意被看见”的正向情绪。正文六种行为支撑温柔，不以条数判幸福，不保证阅读效果。

## 贴近对标的稳健版
老婆爱老公的6种表现，看看你们家的幸福藏在哪一条

清单＋对照＋幸福感，邀请寻找生活中的幸福，而不是声称占几条就一定幸福。

## 分享入口备选
给老公看看：这6件小事里，藏着老婆没说出口的爱

便于妻子分享给伴侣。正文的你仍指妻子，丈夫阅读时需要理解代词，不假称这种视角必然比原文更适合转发。

# 引子

记得他的口味，看得到他的好。走在一起时，也会很自然地挽住他的胳膊。

有些事，你做的时候没想那么多。放在一起才发现，原来自己也给了他这么多温柔。

老婆爱老公的这6种表现，看看哪几条最像你。

# 六图顺序

1. 他的口味，你一直记在心里
2. 不拿别人家的老公，来否定他
3. 真心觉得他好，也愿意说出来
4. 他想做的事，你愿意给他鼓劲
5. 没什么事，也想跟他贴一贴
6. 信得过他，也会让他安心

# 收尾

哪一条让你想到自己？也可以转给他看看，问问他有没有发现这些小小的心意。

不用条条都中，表达爱的方式有很多。你给出的温柔，也值得被认真回应。

# 使用

复制创作提示词.md的完整代码块到ChatGPT网页端，生成6张独立3:4图片。暂用简笔风格，上观点与四行解释，下生活漫画；第1—3图有简短人物台词，第4—6图无气泡。按实际平台规则处理AI标识，不发布参考原图。
