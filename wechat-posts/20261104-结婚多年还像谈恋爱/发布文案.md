# 发布标题

结婚多年还像谈恋爱的6个小细节，占3条就很甜蜜

# 开头

明明天天见，他认真夸你一句，你还是会开心。一起出门办点小事，也会想绕远一点，再多待一会儿。

结婚多年，恋爱的感觉有时就藏在这些小细节里。看看你们占了哪几条？

# 六图顺序

1. 被他夸一句，还是会偷偷开心
2. 再忙，也想和他单独约个会
3. 路再短，也想和他多待一会儿
4. 遇到一点浪漫，还是想拉他一起看
5. 翻到旧合照，还能聊起那时的心动
6. 没什么事，也想先抱他一下

# 收尾

不用条条一样，每对夫妻都有自己的甜蜜方式。

你最近一次觉得“我们还挺像在谈恋爱”，是在哪个瞬间？也可以转给他看看，聊聊你们最像哪一条。

# 使用

标题与大纲均经用户确认，当前不额外交付标题备选。复制同目录创作提示词.md的完整代码块到ChatGPT网页端使用，计划生成6张独立3:4图，不是拼贴。按平台要求处理AI标识，不使用原作者配图发表。
