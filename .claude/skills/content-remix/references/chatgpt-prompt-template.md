# ChatGPT 整组图片创作提示词模板

将模板中的占位内容替换为本次创作的具体设定，保存为项目的 `prompts/chatgpt-batch.md`。以下示例默认 4 张，实际数量以用户要求为准。不能将未填写的模板作为交付，也不能依赖 ChatGPT 读取本地路径或未上传的文件。

## 可整段复制到 ChatGPT 的总提示词

```text
请使用图片生成能力，为以下原创图文主题生成 4 张独立竖版图片。请在本轮尽可能生成全部图片，每张分别输出，按 01—04 顺序对应分镜；不是一张四宫格、拼贴、海报合集或联系表。如果本轮无法生成全部独立图片，请说明已完成的序号，后续按相同设定补齐，不要用文字描述冒充图片。

【主题与叙事】
主题：〔本次原创主题〕
目标读者：〔具体人群〕
情绪递进：〔开场冲突 → 递进 → 转折 → 收束〕

【全组统一设定】
人物：〔年龄、外貌、发型、关系等具体特征〕
服装与道具：〔跨图固定设定〕
场景：〔空间、时段与连续性〕
视觉：〔泛化画风、色盘、材质、光线与镜头语言；不复制特定作者的独特设计〕
画幅：每张独立 3:4 竖版；主体处于中央安全区。
文字模式：直接生成带中文文案的成品图片，将每张指定的“图片内准确文字”排入对应图片，逐字使用，不改写、不添加其他文字。不添加 logo、水印或序号。不需要生成或保留无字版本。
文字排版：〔统一文字位置、字体风格、字号层级、对齐方式与对比度〕；简体中文清晰易读，适合手机阅读，不遮挡人物主体。
构图：〔统一文字区域与安全边距〕

【01｜〔叙事任务〕】
画面：〔完整动作、表情、环境细节、景别、镜头和构图〕
图片内准确文字：〔准确 caption〕

【02｜〔叙事任务〕】
画面：〔完整描述，不使用“同上”省略关键人物与场景设定〕
图片内准确文字：〔准确 caption〕

【03｜〔叙事任务〕】
画面：〔完整描述〕
图片内准确文字：〔准确 caption〕

【04｜〔叙事任务〕】
画面：〔完整描述〕
图片内准确文字：〔准确 caption〕

【质量要求】
每张只表达一个主要事件；人物、服装、光线和场景逻辑保持连续。检查手指、人体结构、透视、反射和物件数量。不要重复同一画面，不要照搬对标素材的独特情节、文字或构图。
```

## 文字核对

整组提示词、`cards.json` 和逐张 `image_prompt` 均使用同一套带字要求，准确文案与 `caption` 一致，不额外交付无字版本。交付时提醒用户逐张核对错字、漏字、重复字、标点和可读性；发现问题时定向修订对应图片，不运行叠字脚本。

## 续生成指令

```text
请延续本对话中已经确认的人物、服装、场景和画风，仅补生成第〔缺失序号〕张。每张分别输出独立竖版图片，不要生成拼图，也不要重复已完成的图片。对应分镜如下：〔粘贴缺失图片的完整分镜及文字模式〕。
```

## 单张修订指令

```text
请仅修订第〔序号〕张，其他图片不变。保留已确认的人物、服装、画风、画幅与构图，只修正：〔具体问题与目标〕。请输出修订后的单张独立图片，不要输出对比拼图。
```

在新对话中补图或修订时，需重新粘贴完整统一设定与对应分镜，并实际上传有权使用的必要参考图。多图输出数量、人物一致性与中文准确性均需检查，不能仅凭提示词保证。
