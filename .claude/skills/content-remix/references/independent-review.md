# agy独立复核

默认两次：10个标题保存后、交用户选择前；完整图片提示词编译并内部检查后、交付前。固定请求模型gemini-3.8-flash-high，effort high。只审查，不接管创作或生图。

```bash
python3 "$SKILL_DIR/scripts/review_agy.py" --workspace "$WORKSPACE" --target "$REFERENCE" --stage titles
python3 "$SKILL_DIR/scripts/review_agy.py" --workspace "$WORKSPACE" --target "$PROJECT" --stage prompt
```

标题目录需有对标分析.md、标题方案.md；文章目录需有大纲、cards.json、创作提示词。脚本只传定位和上述材料，不传作者的通过结论。通过临时工作目录、新会话、plan模式且不调用任何slash Skill，避免项目Skill递归，不复用旧会话、不跳过权限。材料嵌入请求，无需Agent读取原工作区。

注意：agy当前已核实CLI没有无工具开关。plan＋提示不调用工具不是操作系统级只读沙箱，也不能承诺工具彻底禁用。不使用--disable-slash-commands（实测会令--mode plan失效）。不开自动批准，工具权限申请可能导致超时；失败如实记录。请求会发往agy模型服务，沿用已有登录，不修改全局配置。CLI文本模式不证明真实后端模型，记录请求模型与实际模型未核实，不用模型自述冒充调用证据。

报告及元数据写入目标目录记录/标题独立复核.md/json或提示词独立复核.md/json。记录输入SHA256，输入变化即原报告过期；失败覆写为未完成，不能沿用旧通过。默认单次、240秒上限，不无限重试或自动降级到别的模型。

主创必须逐项核实原句证据，记录采纳/不采纳及理由：标题审查处置追加标题方案.md；提示词审查处置追加记录/审核.md。修正后重新编译，涉及本轮实质修改时重新审查一次；仍有分歧如实说明，不声称零问题。修改已确认标题或大纲的实质内容需用户确认，不能自动应用。review_returned只表示拿到输出，不表示语义通过；空回复、明显没审查、权限提示或输出中断都按未完成处理。未完成时不声称已独立审核，向用户说明阻塞或由用户明确跳过。

本环节评估图片计划里的表达，不检查不存在的成图、不要求回传，不新增用户审批环节。
