# 贴图类公众号文章拆解规则

## 分析输出结构（保存为 01-analysis.md）

1. **素材与可信度**：原文标题、来源链接或文件路径、正文和配图是否完整；不能看到的部分标为“未知”。
2. **人群与场景**：读者画像、核心现实处境、用户为什么会转发/收藏（标为推测）。
3. **标题公式**：钩子（冲突、反差、悬念、共鸣、反常识）、字数、节奏；不要直接拿标题替换关键词。
4. **核心表达**：一句话的主题；文章发生了什么/想说什么；具体生活细节。
5. **叙事结构**：首图吸引 → 中段递进 → 末图回扣/释放；逐图记录角色、场景、主要事件、文字、情绪、设计元素和证据出处。
6. **语言风格**：句式长短、口语程度、对话/独白、留白、是否有空泛套话。
7. **视觉风格**：写实/插画/手绘等；画面比例、镜头、用色、光线、固定角色、是否嵌字、文字区；不清楚就标未知。
8. **传播机制**：认同、代入、争议、转发理由、互动提问（只能推测，不假称后台数据）。
9. **抽象可复用规律**：主题如何切、四图各司何职、阅读停留怎样设计；描述结构而不是复制表面表达。
10. **原创避让**：原文独特句式、具体场景、人物、视觉构图有哪些不得复刻；拟转化成哪些不同原创元素。

## 对标贴近度（原创策划交付前填写）

列出保留/改写/避让表，并检查：
1. 并列清单还是连续故事，是否无故换了结构？
2. 气泡、画面、解释等信息层级是否保留？
3. 单图文字量是否与样本相近，是否把解释错误删成标语？
4. 口语、举例、情绪推进是否相近，而非变成概念说明？
5. 泛化画风与版式是否接近，是否无故改成另一个视觉类型？

通用形式允许保留，原句、具体故事、独特角色与构图不照搬。两项以上明显偏离且未获用户要求时，先修订方案。不用“差异化”一项掩盖对标缺失。

## 置信度

- 高：实际读到了完整原文及对应图片。
- 中：读到部分正文或部分图片。
- 低：仅有标题或二手描述，禁止臆测画风与逐图故事。

## 非法或不当模仿的处理

不要删除水印、抹除署名、复用原作者作品作为自己的原创图。可以提炼一般创作手法，但要独立生成文案和画面。原始素材仅用于参考和内部分析，保留来源记录；对外发表时自行核查授权和平台规范。
