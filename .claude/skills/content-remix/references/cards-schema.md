# cards.json 结构（AI 必须生成，供脚本读取）

示例字段：

```json
{
  "title": "周末不一定要安排满",
  "audience": "忙碌的年轻家庭",
  "theme": "放下周末绩效感",
  "style_guide": "生活抓拍摄影感；奶油白、暖棕、绿色点缀；柔和晨光；自然情绪；3:4竖版",
  "characters": "成年夫妻与学龄儿童，衣着日常，容貌和服装跨四张保持一致",
  "cards": [
    {
      "index": 1,
      "role": "冲突开场",
      "caption": "周末刚开始，怎么又像在赶时间？",
      "alt": "餐桌上堆着计划表，一家人准备出门",
      "image_prompt": "单张3:4竖版原创生活摄影。温暖晨光，家庭餐桌上有出行计划表与水杯，一对成年夫妻及小学生正忙着出门，自然动作...画面下方设置清晰文字区域，直接排入简体中文文案“周末刚开始，怎么又像在赶时间？”，逐字准确，字体清晰易读、对比充足，不遮挡主体。不添加其他文字、logo、水印、边框，不拼图。"
    }
  ]
}
```

`cards` 通常恰好 4 个对象，`index` 为 1..4。禁止用示例文本直接作为最终作品。每个 `caption` 保存图片中全部准确文案（气泡与底部解释按阅读顺序用换行分隔）。极简型图片可用12–40字；对标为话术＋解释卡时，保留短气泡和约60–100字解释，不套用极简字数限制。可增设 `bubble_text` 和 `body_text`，但 `caption` 必须等于二者用换行拼接的完整文本。`image_prompt` 必须足够详细，并包含风格统一要素和本张的独特动作及画面留白。

**持续性**：统一人物年龄、发型、服饰、场景逻辑，不能每张图意外变成不同人物。独立生成不能保证一致，可使用宿主提供的参考图编辑能力迭代。

**字体排版**：直接由 ChatGPT 生成带中文文案的图片。每个 `image_prompt` 必须包含与 `caption` 完全一致的准确文字，以及文字位置、字体风格和可读性要求；若分气泡与底部解释两区，先完整列出caption，再明确各区分配与换行，不能只记录气泡、遗漏底文；整组提示词也采用同一带字版本。不要求保留无字图片，不执行后期叠字。实际生成后逐字核对，错误通过单张修订纠正。

**优先交付**：先输出 `prompts/chatgpt-batch.md`，内容按 `chatgpt-prompt-template.md` 填写，可整段复制到 ChatGPT 请求多张独立带字图片；不能将一张四宫格当作多张交付。
