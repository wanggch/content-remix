# 账号创作规律档案（由多篇样本归纳，不是复制模版）

- 对标账号/样本：名称、样本链接和日期，禁止编造阅读量、转发率等后台数据
- 样本数量：至少 2 篇才对账号风格作一般性判断，最好 3–5 篇覆盖不同主题
- 主要受众与生活场景：
- 高频选题母题：
- 标题公式（抽象，不复制现成标题）：
- 图数及叙事功能：开篇 / 递进 / 转折 / 收束
- 文案特点：长短、口语程度、人物视角、真实生活细节
- 视觉规律：画种、构图、角色、光线、色盘、文字位置、留白、比例
- 转发/收藏驱动：标为创作推测，不得当成实际运营数据
- 适合原创延伸的 5 个新角度：
- 不应复刻的独特表达：
- 不确定项与反例：

> 建议将 `style-profile.md` 放进下次创作项目，输入“按这个风格档案创作全新四图”，不要把具体原图或原文当作模板复制。
